# StudySprint

A lightweight Pomodoro timer and session task tracker built to stay focused during study sessions without distractions.

**Live Demo:** https://study-sprint-tan.vercel.app

## Features
- Preset & Custom Timers: Focus (25m), Short Break (5m), Long Break (15m), or custom durations (1–180 min).
- Input Validation: Prevents invalid or empty inputs for both timers and tasks.
- Session Tasks: Add, complete, and remove tasks saved in browser localStorage.
- Audio Notification: Built-in Web Audio API chime when a session finishes.
- Theme Toggle & Keyboard Shortcuts: Switch between Dark/Light themes (saved in localStorage), use `Space` to start/pause and `R` to reset, and reset completed session count anytime.
- Responsive Design: Works cleanly on desktop and mobile screens.

## Tech Stack
- HTML5, CSS3, Vanilla JavaScript

## Running Locally
Clone the repository and open index.html directly in your browser.
